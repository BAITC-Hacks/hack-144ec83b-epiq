# Проверка соответствия техническому заданию

Проверка выполнена по исходному ТЗ HackAlem AI для кейса «Граф денег».

## Обязательные функции

| Требование | Статус | Реализация и проверка |
|---|---|---|
| Один запуск от parquet до трёх CSV | Выполнено | `python run.py`; отдельная копия с новой `.venv`, установка и расчёт проверены; см. `release-verification.md` |
| Роль и оценка для всех 2 248 узлов | Выполнено | `nodes_roles.csv`: 2 248 уникальных gid, обязательные поля заполнены |
| Объяснимые критерии ролей | Выполнено | Пороговые правила и веса описаны в README и `docs/architecture.md` |
| Кластеризация | Выполнено | Louvain внутри слабосвязных компонент; `cluster_id` назначен каждому узлу |
| Топ не менее 20 узлов и визуализация | Выполнено | `top_nodes.csv`, поиск по gid, направленный граф, карточка и связи узла |

## Ограничения данных

| Ограничение | Учёт в решении |
|---|---|
| Обрыв на четвёртом колене | Узлы `depth=4` не получают роли `terminal` и `transit` только из-за отсутствия выхода |
| Неполный входящий поток seed | Для seed не применяются роли, зависящие от отношения выхода ко входу |
| Исходящий объём выше наблюдаемого входящего | Интерфейс отмечает неполный контур и предлагает запросить полный входящий оборот и начальный остаток |
| Переводы ниже 5 000 KZT отсутствуют | Ограничение указано в документации; скрытые переводы не достраиваются |
| Нет персональных атрибутов | Используются только gid, граф, суммы и даты; новые сведения о клиентах не создаются |
| Нет размеченных ролей | Оценки названы силой экспертного правила, а не вероятностью виновности |

## Дополнительные функции

| Бонусный пункт | Статус | Реализация |
|---|---|---|
| Учёт обрыва графа | Выполнено | `truncated_by_depth`, предупреждение и отдельная рекомендация запроса |
| Временные паттерны | Выполнено | Однодневный и двухдневный транзит, синхронные плательщики, дневные всплески |
| Повторяющиеся маршруты и циклы | Частично | `repeated_routes.csv` и `route_episodes.csv`: два и более непересекающихся датированных эпизода. Структурные циклы выявляются через сильносвязные компоненты; хронология полного кольца не проверяется |
| Детекция аномалий | Выполнено | Оборот и связность сравниваются с узлами того же колена; формируется `anomaly_score` |
| Устойчивость сети | Выполнено | `resilience.csv` и экран стресс-теста удаления топ-N узлов |
| Ассистент аналитика | Реализован в MVP | OpenAI Responses API, вопросы обычным языком, история, семь разрешённых функций чтения, ссылки на данные. Живые запросы проверены на вымышленном графе и, с разрешения пользователя, на выгрузке хакатона; результаты сверены с локальными расчётами |
| Автокарточка узла | Выполнено | Роль, приоритет, признаки, ограничения, связи, операции и решение аналитика |
| Оценка полноты | Выполнено | `data_gap` и `next_request` для каждого узла |

## Контрольные показатели последнего запуска

- 2 248 узлов, 3 119 рёбер, 4 840 транзакций;
- 81 seed и 444 узла на границе `depth=4`;
- полный расчёт на контрольном наборе значительно быстрее лимита в пять минут;
- входные файлы фиксируются SHA-256 в `run_manifest.json`.

Отдельно реализовано сравнение пяти вкладов приоритета. Технические проверки
не измеряют качество ролей: размеченного эталона нет. Этот чек-лист не является
оценкой жюри и не гарантирует баллы или место.
