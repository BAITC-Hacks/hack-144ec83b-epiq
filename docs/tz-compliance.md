# Проверка соответствия техническому заданию

Проверка выполнена по исходному ТЗ HackAlem AI для кейса «Граф денег».

## Обязательные функции

| Требование | Статус | Реализация и проверка |
|---|---|---|
| Один запуск от parquet до трёх CSV | Выполнено | `money-graph --data ./data --out ./out`; на контрольных данных расчёт занимает менее 10 секунд |
| Роль и оценка для всех 2 248 узлов | Выполнено | `nodes_roles.csv`: 2 248 уникальных gid, обязательные поля заполнены |
| Объяснимые критерии ролей | Выполнено | Пороговые правила и веса описаны в README и `docs/architecture.md` |
| Кластеризация | Выполнено | Louvain внутри слабосвязных компонент; `cluster_id` назначен каждому узлу |
| Топ не менее 20 узлов и визуализация | Выполнено | `top_nodes.csv`, поиск по gid, направленный граф, карточка и связи узла |

## Ограничения данных

| Ограничение | Учёт в решении |
|---|---|
| Обрыв на четвёртом колене | Узлы `depth=4` не получают роли `terminal` и `transit` только из-за отсутствия выхода |
| Неполный входящий поток seed | Для seed не применяются роли, зависящие от отношения выхода ко входу |
| Исходящий объём выше наблюдаемого входящего | Интерфейс отмечает неполный контур и предлагает запросить полный входящий оборот и начальный остаток |
| Переводы ниже 5 000 KZT отсутствуют | Ограничение указано в документации; скрытые переводы не достраиваются |
| Нет персональных атрибутов | Используются только gid, граф, суммы и даты; новые сведения о клиентах не создаются |
| Нет размеченных ролей | Оценки названы силой экспертного правила, а не вероятностью виновности |
