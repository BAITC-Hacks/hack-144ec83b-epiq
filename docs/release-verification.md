# Проверка версии правил 1.3.0

Дата: 23 сентября 2026 года. Проверка на локальном Windows, Python 3.14.7.

## Отдельное окружение

В отдельный каталог скопированы исходники и три Parquet-файла организатора.
В начале не было `.venv`, установленных в ней пакетов и готовых результатов.
`python run.py --no-ui` создал окружение, установил зависимости и завершил расчёт.
Использовался тот же компьютер, интернет и доступный кэш pip. Проверка на новой
чистой операционной системе не выполнялась.

После синхронизации итогового кода повторён полный запуск:

```powershell
python run.py --port 8511
```

Получены 2 248 узлов, 105 кластеров и обязательные CSV. Длительность расчёта
в `run_manifest.json` — **8,355 с**; сюда не входят установка пакетов и запуск UI.
Streamlit запустился на 8511, запрос `/_stcore/health` вернул `200 ok`.
После проверки вспомогательный сервер остановлен.

Зафиксированы Python 3.14.7, pandas 3.0.6, NetworkX 3.7, Streamlit 1.64.0.
Точные диапазоны зависимостей указаны в `requirements.txt`; lock-файла пока нет.

## Функциональные проверки

- `pytest`: **20 тестов прошли**, включая сквозной Parquet → CSV → демо-отчёт.
- `scripts/smoke_ui.py` в отдельном окружении: все восемь режимов открылись
  без исключений; проверены поиск сборщика, сумма вкладов рейтинга, общие пути
  из пяти seed, выбор повторяющегося маршрута, эпизоды, предупреждение depth=4
  и добавление решения в перечень.
- В браузере проверены актуальный экран и читаемость таблицы сравнения.
- На исходной поставке найдено **5 повторяющихся маршрутов**, всего **11 эпизодов**.
  Эпизоды разных маршрутов могут использовать одну операцию; это не 11
  независимых подтверждённых схем и не сумма уникального денежного потока.
- Три примера автоматически записаны в `out/demo_cases.md` и `.json`.

При проверке pytest использовался новый временный каталог внутри рабочей области:
системный каталог pytest на этой машине оказался недоступен по правам.
Это ограничение среды запуска, а не изменение тестовых ожиданий.
