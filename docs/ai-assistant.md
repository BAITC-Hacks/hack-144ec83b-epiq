# AI-ассистент аналитика

Режим «AI · OpenAI» использует `gpt-5-mini` через Responses API. Модель понимает
вопрос и запрашивает данные через локальные функции. Роли, суммы, приоритет,
пути и повторения рассчитывает Python. Локальный режим по ключевым словам
работает независимо от внешнего сервиса.

## Доступные операции

| Функция | Что проверяет |
|---|---|
| `rank_nodes` | Совместные фильтры роли, охвата seed, числа плательщиков, глубины, доли выхода; сортировка по приоритету или аномальности |
| `node_profile` | Карточка gid, место в рейтинге, пять вкладов, пробелы и следующий запрос |
| `compare_nodes` | Вклады приоритета для 2–5 разных участников |
| `find_common_recipients` | Общие получатели из каждого из 2–5 seed, пути до четырёх переходов |
| `transaction_history` | Вход/выход участника, даты включительно, итоги всего фильтра и до 20 последних строк |
| `find_repeated_routes` | Повторяющиеся цепочки, число эпизодов, до трёх примеров каждого маршрута |
| `dataset_summary` | Размер, период, возможности и ограничения выгрузки без отдельных операций |

Вопросы, которые не укладываются в эти операции, не являются произвольными SQL-
или Python-запросами. Модель должна уточнить вопрос или сообщить ограничение.
Пример составного фильтра: «Найди сборщиков с пятью плательщиками, которые
отдают не больше 10% входа». Для отношения входа и выхода исключаются seed
и depth=4 из-за неполноты наблюдения.

## Поток запроса

1. Пользователь включает передачу данных и отправляет вопрос.
2. Передаются вопрос, выбранный gid и до шести последних сообщений.
3. Модель выбирает одну разрешённую функцию; JSON Schema проверяет аргументы.
4. Python читает готовые таблицы и вычисляет результат. Он получает метку `[D1]`.
5. Модель формулирует ответ; при необходимости выполняются ещё два шага проверки.
6. Интерфейс показывает ответ и раскрываемые данные `[D1]`, `[D2]`, `[D3]`.

Ограничения: четыре API-запроса на вопрос, три вызова функций, до 2200 выходных
токенов на запрос, 35 секунд ожидания каждого запроса, без автоматических повторов.
Обновление страницы или смена режима не отправляют вопрос заново.

## Ключ и данные

Ключ читается из `OPENAI_API_KEY` или локального `.streamlit/secrets.toml`.
Файл исключён из Git; ключ не включается в сообщения, журнал инструментов и ошибки.
Пример конфигурации находится в `.streamlit/secrets.toml.example`.
`OPENAI_MODEL` можно изменить, но проверен именно `gpt-5-mini`; альтернативная модель
должна поддерживать Responses API, function calling и указанные параметры reasoning.

Внешнему API передаются ограниченные результаты выбранных функций, включая gid,
суммы, даты и пути. Полные Parquet-файлы не загружаются. Используется `store=false`;
это параметр запроса, а не обещание полного отсутствия хранения у провайдера.
Пользователь должен иметь право передавать эти данные. При отказе от передачи
можно использовать все локальные экраны и режим правил.

Модель не получает файловый доступ, командную оболочку, банковские API или функции
записи. Идентификаторы сериализуются строками, чтобы не терять точность. Неизвестные
полные gid и ссылки на несуществующие источники отклоняются. Проверка не доказывает
корректность всех чисел и смысловых выводов; аналитик сверяет ответ с источниками.

## Проверки 23 сентября 2026 года

- Ключ принят OpenAI; доступ к `gpt-5-mini` подтверждён.
- 31 тест прошёл: прежняя логика, инструменты AI, даты и лимиты, точность gid,
  обработка ошибок, отсутствие повторной отправки и необходимость разрешения.
- Два настоящих запроса выполнены на полностью вымышленном графе из пяти узлов:
  карточка участника и общий получатель seed 11 и 12. Вызваны нужные функции,
  проверены параметры и результаты; ответы сохранены локально в
  `out/ai_smoke_synthetic.json`.
- После отдельного разрешения пользователя выполнены два запроса на выгрузке
  хакатона: объяснение приоритета и общий получатель двух seed. Число плательщиков,
  суммы, вклады рейтинга и пути сверены с локальными результатами функций.
  Передавались ограниченные результаты, без загрузки полных файлов. Ответы
  сохранены в `out/ai_smoke.json`, который исключён из Git.
- Это функциональная проверка интеграции, а не измерение точности на эталонной
  разметке и не гарантия отсутствия ошибок модели.

Воспроизведение на вымышленных данных: `python scripts/smoke_ai.py --live --synthetic`
из подготовленной виртуальной среды. Скрипт использует API-кредиты. Без `--synthetic`
он читает настоящую выгрузку; этот вариант запускать только при разрешении её передачи.

Протокол вызовов реализован по [официальному руководству OpenAI](https://developers.openai.com/api/docs/guides/function-calling).
